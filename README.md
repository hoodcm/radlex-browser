# RadLex browser

A fast static term browser for [RadLex](https://github.com/RSNA/RadLex), built automatically from the newest version tag of the official `RSNA/RadLex` repository and published at [hoodcm.github.io/radlex-browser](https://hoodcm.github.io/radlex-browser/).
